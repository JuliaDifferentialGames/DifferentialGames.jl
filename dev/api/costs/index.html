Costs & Objectives API

Stage Costs

DifferentialGamesBase.LQStageCost — Type
LQStageCost{T, QM, RM, MM, QVM, RVM} <: AbstractStageCost

Unified LTI/LTV quadratic stage cost.

Mathematical Form

ℓᵢ(x, uᵢ, k) = ½ xᵀQ(k)x + ½ uᵢᵀR(k)uᵢ + xᵀM(k)uᵢ + q(k)ᵀx + r(k)ᵀuᵢ + c

Always use get_Q(cost, k), get_R(cost, k), etc. in solver hot loops.

source

Diagonal convenience constructor: DiagonalLQStageCost(q_diag, r_diag) creates an LQStageCost with diagonal Q = diagm(q_diag) and R = diagm(r_diag).

Terminal Costs

DifferentialGamesBase.LQTerminalCost — Type
LQTerminalCost{T} <: AbstractTerminalCost

Quadratic terminal cost: Vᵢ(x(tf)) = ½ x(tf)ᵀQf x(tf) + qfᵀx(tf) + cf

source

Diagonal convenience constructor: DiagonalLQTerminalCost(qf_diag) creates an LQTerminalCost with diagonal Qf = diagm(qf_diag).

Player Objectives

DifferentialGamesBase.PlayerObjective — Type
PlayerObjective{SC <: AbstractStageCost, TC <: AbstractTerminalCost}

Bundles a player's stage and terminal cost functions.

Fields

  • player_id : Player index (1-based)
  • stage_cost : Stage cost evaluated at each timestep
  • terminal_cost : Terminal cost evaluated at x(tf)
  • scaling : Global cost scaling factor (default 1.0)
source

Custom Cost Functions

All cost types must implement the AbstractStageCost or AbstractTerminalCost interface from DifferentialGamesBase. The required methods are:

stage_cost(cost::MyCost, x, u, t) -> Real
terminal_cost(cost::MyCost, x)    -> Real

For LQ costs you can use the diagonal convenience constructors:

stage = DiagonalLQStageCost([1.0, 0.5, 0.1], [0.01])   # 3 states, 1 control
term  = DiagonalLQTerminalCost([10.0, 5.0, 1.0])
